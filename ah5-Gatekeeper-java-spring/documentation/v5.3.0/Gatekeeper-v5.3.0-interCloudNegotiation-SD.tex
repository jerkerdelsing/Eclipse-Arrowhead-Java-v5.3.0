\section{Overview}
\label{sec:overview}

This document describes the \texttt{inter\allowbreak{}Cloud\allowbreak{}Negotiation} service, which provides negotiation of the use of one provider in a neighbour cloud and opening of the GateTunnel session through which the consumer calls it.
It is produced by the Gatekeeper system \cite{gk-sysd} in service version 5.2.2.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interface is specified in the HTTP/TLS/JSON IDD \cite{gk-interCloudNegotiation-http-idd}.

\subsection{Significant Prior Art}

Successor of the Arrowhead 4.6 Gatekeeper inter-cloud negotiation (ICN, \texttt{/\allowbreak{}init\_\allowbreak{}icn}).

\subsection{How This Service Is Meant to Be Used}

Dynamic\allowbreak{}Service\allowbreak{}Orchestration calls \texttt{negotiate} with the target cloud, provider, service and operations. The provider cloud's Gatekeeper checks authorization and opens a provider session at its GateTunnel; the local Gatekeeper opens the consumer session at the local GateTunnel and returns its endpoint as the provider interface.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

Only the negotiated operations (method and path) can be used through the session. An AH-GT-1 (end-to-end) peer is refused rather than downgraded.
