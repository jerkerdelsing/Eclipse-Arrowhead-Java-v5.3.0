# Notice

SoSConfigurator was written on 2026-10-29 for this distribution, following the design of ah5-LocalCloudConfigurator-go. It does not copy upstream Arrowhead code.
Its ColonyOS client is a Java implementation of the ColonyOS v1.9.10 RPC protocol (github.com/colonyos/colonies, MIT licence); no ColonyOS code is included.
Dependencies, resolved by Maven: Jackson Databind 2.18.4 (Apache-2.0), Bouncy Castle bcprov-jdk18on 1.83 (MIT), JUnit Jupiter 5.12.2 (EPL-2.0, tests only).
