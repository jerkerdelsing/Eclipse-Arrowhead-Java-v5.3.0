\section{Service definition and contract}
The system produces \path|generalManagement| version 1.0.0. The secure HTTPS base path is \path|/sosconfigurator/general/mgmt|. This interface is restricted by the common management filter; the secure standalone policy is Sysop-only. Browser console sessions are not a replacement for this management identity.
\section{Operations and data models}
\paragraph{get-log.} POST \path|/sosconfigurator/general/mgmt/logs| consumes an optional JSON \path|LogRequestDTO| and returns \path|LogEntryListResponseDTO| with HTTP 200. LogRequestDTO has \path|pagination| (PageDTO), \path|from|, \path|to|, \path|severity| and \path|logger|. PageDTO fields are integer \path|page|, integer \path|size|, string \path|direction| and string \path|sortField|. Validation and defaults are those of the vendored common LogService/LogValidation.

The response has \path|entries| (array of LogEntryDTO) and integer \path|count|. An entry contains strings \path|logId|, \path|entryDate|, \path|logger|, \path|severity|, \path|message| and \path|exception|; the record omits empty values. Count and pagination must not be inferred from array length alone.

\paragraph{get-config.} GET \path|/sosconfigurator/general/mgmt/get-config| accepts optional repeated \path|keys| query parameters and returns \path|KeyValuesDTO| with HTTP 200. KeyValuesDTO contains \path|map|, a string-to-string mapping. It exposes the common/system public configuration keys, not a secret-store export. The system-specific public keys include catalog file, status timeout, API whitelist and console port.
\section{Security and failure behavior}
Mutual TLS and the configured identity policy authenticate a secure caller. Common management authorization is applied independently of \path|sosConfiguration| grants. Invalid filters, missing identity, denied management rights and unavailable backing storage are governed by common validation/error handling; these two handlers do not introduce a bespoke SoS planning-error envelope. Response DTO null/empty omission follows the vendored record annotations.
