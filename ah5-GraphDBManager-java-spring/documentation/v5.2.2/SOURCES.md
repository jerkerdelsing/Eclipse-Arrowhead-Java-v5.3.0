# Sources

Structure, cover metadata and macros follow the Eclipse Arrowhead LaTeX templates
(`roadmap/Documentation_templates/LaTeX/template_{sysd,sysdd,sd,idd}.tex`, copied to `templates/`); `arrowhead.cls`
and the logo are copied from there.

These documents were derived on 2026-10-28 from the DataManager 5.2.2 set (`../ah5-DataManager-java-spring/documentation/v5.2.2`,
generated by `documentation-tools`) and then edited by hand for GraphDBManager: names, service definitions
(`graphDataProxy`, `graphDataHistorian`), paths (`/graphdbmanager/...`), port 8467 and everything about persistence
(GraphDB repository, RDF vocabulary, SPARQL queries, GraphDB container, deployment, verification). The content was
checked against `ah5-GraphDBManager-java-spring` (`GraphDBManagerSystemInfo.java`, the controllers, `graphdb/`,
`deployment/graphdb/`) and `Arrowhead-test-cloud-java/compose.yaml`. They are not produced by the generator: edit the
`.tex` files. They are marked DRAFT until quality assurance.
