\section{Overview}
\label{sec:overview}

This document describes the \texttt{service\allowbreak{}Orchestration\allowbreak{}Lock\allowbreak{}Management} service, which provides operator management of orchestration locks, the exclusive reservations of service instances.
It is produced by the DynamicServiceOrchestration system \cite{dso-sysd} in service version 1.0.0.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interface is specified in the HTTP/TLS/JSON IDD \cite{dso-serviceOrchestrationLockManagement-http-idd}. The MQTT binding is specified in the MQTT/TLS/JSON IDD \cite{dso-serviceOrchestrationLockManagement-mqtt-idd}.

\subsection{Significant Prior Art}

New in Arrowhead 5.

\subsection{How This Service Is Meant to Be Used}

When a consumer requests exclusivity (\texttt{exclusivity\allowbreak{}Duration}), Dynamic\allowbreak{}Service\allowbreak{}Orchestration locks the chosen instance for it. Operators can also create locks, query them and remove them.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

Only providers whose service instance metadata allows exclusivity can be reserved. Locks expire and are removed by the cleaner job.
