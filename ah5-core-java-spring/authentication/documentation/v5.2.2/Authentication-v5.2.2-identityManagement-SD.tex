\section{Overview}
\label{sec:overview}

This document describes the \texttt{identityManagement} service, which provides operator management of the identities known to Authentication (systems, their credentials and sysop flag) and of their active sessions.
It is produced by the Authentication system \cite{auth-sysd} in service version 1.0.0.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interface is specified in the HTTP/TLS/JSON IDD \cite{auth-identityManagement-http-idd}. The MQTT binding is specified in the MQTT/TLS/JSON IDD \cite{auth-identityManagement-mqtt-idd}.

\subsection{Significant Prior Art}

New in Arrowhead 5.

\subsection{How This Service Is Meant to Be Used}

Operators and the onboarding procedure create identities before a system's first login, update credentials or the sysop flag, query identities and sessions, and close sessions of misbehaving systems.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

Access is governed by the management policy of Authentication (\texttt{management.\allowbreak{}policy=\allowbreak{}authorization} by default: Consumer\allowbreak{}Authorization decides). In this workspace only \texttt{Sysop} is created as a sysop identity (finding J23). Passwords are stored as hashes and never returned.

\section{Service Interface}
\label{sec:operations}

This section describes the interfaces to the \texttt{identityManagement} service.
In particular, each subsection names an abstract operation, an input type and an output type, in that order.
The input type is named inside parentheses, while the output type is preceded by a colon.
Input and output types are only denoted when accepted or returned, respectively, by the interface in question.

All abstract data types named in this section are defined in Section \ref{sec:model}.

The following interface operations are available.

\osubsection{identity-mgmt-create}{\mref[Identity\allowbreak{}List\allowbreak{}Mgmt\allowbreak{}Create\allowbreak{}Request]{IdentityListMgmtCreateRequest}}{\mref{IdentityListMgmtResponse}}

Creates identities with credentials of the given authentication method.

\osubsection{identity-mgmt-update}{\mref[Identity\allowbreak{}List\allowbreak{}Mgmt\allowbreak{}Update\allowbreak{}Request]{IdentityListMgmtUpdateRequest}}{\mref{IdentityListMgmtResponse}}

Updates credentials and sysop flag of identities.

\osubsection{identity-mgmt-remove}{\pref{List}$<$\allowbreak{}\pref{Name}$>$}{}

Removes identities by system name, closing their sessions.

\osubsection{identity-mgmt-query}{\mref{IdentityQueryRequest}}{\mref{IdentityListMgmtResponse}}

Returns a page of identities matching the filter.

\osubsection{identity-mgmt-session-close}{\pref{List}$<$\allowbreak{}\pref{Name}$>$}{}

Closes the sessions of the named systems.

\osubsection{identity-mgmt-session-query}{\mref[Identity\allowbreak{}Session\allowbreak{}Query\allowbreak{}Request]{IdentitySessionQueryRequest}}{\mref[Identity\allowbreak{}Session\allowbreak{}List\allowbreak{}Mgmt\allowbreak{}Response]{IdentitySessionListMgmtResponse}}

Returns a page of active sessions.
