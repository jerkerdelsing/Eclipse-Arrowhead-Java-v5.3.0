\section{Overview}
\label{sec:overview}

This document describes the \texttt{serviceDiscovery} service, which provides registration and lookup of service instances: which provider offers which service definition, in which version, through which interfaces and with which security policy.
It is produced by the ServiceRegistry system \cite{sr-sysd} in service version 1.0.0.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interface is specified in the HTTP/TLS/JSON IDD \cite{sr-serviceDiscovery-http-idd}. The MQTT binding is specified in the MQTT/TLS/JSON IDD \cite{sr-serviceDiscovery-mqtt-idd}.

\subsection{Significant Prior Art}

Successor of the Arrowhead 4.x ServiceRegistry \texttt{register}, \texttt{unregister} and \texttt{query} operations. In 5.x a service instance is identified by \texttt{\textless{}System\textgreater{}\textbar{}\allowbreak{}\textless{}service\allowbreak{}Definition\textgreater{}\textbar{}\allowbreak{}\textless{}version\textgreater{}}, and interfaces are described by interface templates instead of fixed interface names.

\subsection{How This Service Is Meant to Be Used}

A provider calls \texttt{register} for each service it offers (creating or replacing its instance), and \texttt{revoke} when it stops offering it. Consumers normally do not call \texttt{lookup} directly: they ask an orchestrator, which looks up the candidates. With \texttt{service.\allowbreak{}discovery.\allowbreak{}policy=\allowbreak{}restricted} (default) a direct \texttt{lookup} of other than the core services is reserved to sysops and the systems in \texttt{service.\allowbreak{}discovery.\allowbreak{}direct.\allowbreak{}access}.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

A system can only register services under its own name. In this workspace the service definitions of the core and support systems are reserved for their owning systems (\texttt{service.\allowbreak{}definition.\allowbreak{}reserved}, finding J9); other registrations of them are refused with 403. Interfaces must conform to a known interface template unless \texttt{service.\allowbreak{}discovery.\allowbreak{}interface.\allowbreak{}policy} is \texttt{extendable} or \texttt{open}. Registration says nothing about authorization: whether a consumer may use the instance is decided by Consumer\allowbreak{}Authorization.

\section{Service Interface}
\label{sec:operations}

This section describes the interfaces to the \texttt{serviceDiscovery} service.
In particular, each subsection names an abstract operation, an input type and an output type, in that order.
The input type is named inside parentheses, while the output type is preceded by a colon.
Input and output types are only denoted when accepted or returned, respectively, by the interface in question.

All abstract data types named in this section are defined in Section \ref{sec:model}.

The following interface operations are available.

\osubsection{register}{\mref[Service\allowbreak{}Instance\allowbreak{}Create\allowbreak{}Request]{ServiceInstanceCreateRequest}}{\mref{ServiceInstanceResponse}}

Registers a service instance of the requesting system. An existing instance with the same identifier is replaced. Unknown service definitions are created; interfaces are validated against their templates.

\osubsection{lookup}{\mref[Service\allowbreak{}Instance\allowbreak{}Lookup\allowbreak{}Request]{ServiceInstanceLookupRequest}}{\mref[Service\allowbreak{}Instance\allowbreak{}List\allowbreak{}Response]{ServiceInstanceListResponse}}

Returns the service instances matching all given filters. Under the restricted discovery policy, a requester without direct access only receives instances whose service has the \texttt{unrestricted\allowbreak{}Discovery} metadata (the core services). With \texttt{verbose=\allowbreak{}true} the provider and device details are included.

Optional parameter: \texttt{verbose}.

\osubsection{revoke}{\pref{Identifier}}{}

Removes a service instance of the requesting system. Returns 200 if removed, 204 if it did not exist.
