\section{Overview}
\label{sec:overview}

This document describes the \texttt{qualityEvaluation} service, which provides quality-of-service evaluation of candidate providers from measurements of the devices hosting them (round-trip time, CPU load, memory use, network load).
It is produced by the DeviceQoSEvaluator system \cite{dqe-sysd} in service version 1.0.0.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interfaces are specified in the HTTP/TLS/JSON IDD \cite{dqe-qualityEvaluation-http-idd} and the MQTT/TLS/JSON IDD \cite{dqe-qualityEvaluation-mqtt-idd}.

\subsection{Significant Prior Art}

New in Arrowhead 5; Arrowhead 4.x had QoS monitoring inside the Orchestrator.

\subsection{How This Service Is Meant to Be Used}

Dynamic\allowbreak{}Service\allowbreak{}Orchestration calls \texttt{filter} or \texttt{sort} with the candidate providers and the consumer's QoS requirement (\texttt{enable.\allowbreak{}qos=\allowbreak{}true}). The evaluator combines the requested metrics with their weights over the time window and filters by the threshold or sorts by the score.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

Only providers whose devices are measured can be evaluated; others are reported in the warnings. Measurements are taken by the evaluator (RTT) and device agents (augmented metrics).

\section{Service Interface}
\label{sec:operations}

This section describes the interfaces to the \texttt{qualityEvaluation} service.
In particular, each subsection names an abstract operation, an input type and an output type, in that order.
The input type is named inside parentheses, while the output type is preceded by a colon.
Input and output types are only denoted when accepted or returned, respectively, by the interface in question.

All abstract data types named in this section are defined in Section \ref{sec:model}.

The following interface operations are available.

\osubsection{filter}{\mref{QoSEvaluationRequest}}{\mref[Qo\allowbreak{}SEvaluation\allowbreak{}Filter\allowbreak{}Response]{QoSEvaluationFilterResponse}}

Returns the providers that meet the threshold of the weighted metrics, and the dropped ones.

\osubsection{sort}{\mref{QoSEvaluationRequest}}{\mref[Qo\allowbreak{}SEvaluation\allowbreak{}Sort\allowbreak{}Response]{QoSEvaluationSortResponse}}

Returns the providers ordered by the weighted metrics, best first.
