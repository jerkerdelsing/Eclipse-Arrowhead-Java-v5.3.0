\section{Overview}
\label{sec:overview}

This document describes the \texttt{eventPublish} service, which provides publication of events to the subscribers of their event type.
It is produced by the EventHandler system \cite{eh-sysd} in service version 1.0.0.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interface is specified in the HTTP/TLS/JSON IDD \cite{eh-eventPublish-http-idd}.

\subsection{Significant Prior Art}

Successor of the Arrowhead 4.6 EventHandler publish service.

\subsection{How This Service Is Meant to Be Used}

A publisher calls \texttt{publish} with the event type, payload and metadata; the EventHandler posts the event to every matching subscriber's \texttt{notifyUri} with its own certificate and identity token.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

Delivery is asynchronous and best effort; the result only counts matched subscriptions and accepted deliveries. With \texttt{service.\allowbreak{}authorization.\allowbreak{}enabled=\allowbreak{}true} publishing needs a grant.

\section{Service Interface}
\label{sec:operations}

This section describes the interfaces to the \texttt{eventPublish} service.
In particular, each subsection names an abstract operation, an input type and an output type, in that order.
The input type is named inside parentheses, while the output type is preceded by a colon.
Input and output types are only denoted when accepted or returned, respectively, by the interface in question.

All abstract data types named in this section are defined in Section \ref{sec:model}.
