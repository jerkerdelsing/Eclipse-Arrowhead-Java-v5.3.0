\section{Overview}
\label{sec:overview}

This document describes the \texttt{generalManagement} service, which provides general management of the Translation\allowbreak{}Manager system: reading its log entries and its configuration.
It is produced by the TranslationManager system \cite{tm-sysd} in service version 1.0.0.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interfaces are specified in the HTTP/TLS/JSON IDD \cite{tm-generalManagement-http-idd} and the MQTT/TLS/JSON IDD \cite{tm-generalManagement-mqtt-idd}.

\subsection{Significant Prior Art}

New in Arrowhead 5; every 5.x core system offers it.

\subsection{How This Service Is Meant to Be Used}

Operators and LocalCloudManager read recent log entries (stored in the system's database) with \texttt{get-\allowbreak{}log} and the effective configuration with \texttt{get-\allowbreak{}config}.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

Access is governed by the management policy of Translation\allowbreak{}Manager. \texttt{get-\allowbreak{}config} returns only non-secret configuration keys.

\section{Service Interface}
\label{sec:operations}

This section describes the interfaces to the \texttt{generalManagement} service.
In particular, each subsection names an abstract operation, an input type and an output type, in that order.
The input type is named inside parentheses, while the output type is preceded by a colon.
Input and output types are only denoted when accepted or returned, respectively, by the interface in question.

All abstract data types named in this section are defined in Section \ref{sec:model}.

The following interface operations are available.

\osubsection{get-log}{\mref{LogRequest}}{\mref{LogEntryListResponse}}

Returns a page of the system's log entries matching the filter.

\osubsection{get-config}{}{\mref{KeyValues}}

Returns the effective values of the requested configuration keys. Only the public keys of the system are answered; other keys, including all secrets, are ignored.

As a complement to the explicitly defined types in this section, there is also a list of implicit primitive types in Section \ref{sec:model:primitives}, which are used to represent things like hashes and identifiers.
