# SysMonitor 5.2.2 package

This folder collects the SysMonitor design documentation and the deployed reference implementation for the Arrowhead 5.2.2 test cloud.

## Layout

- The current Arrowhead documentation (SysD, SysDD, SD and IDD per service) is in `../documentation/v5.2.2/`, generated by `../../documentation-tools` for the deployed JavaSupportRuntime implementation (role `sysmonitor`); the earlier `LaTeX/` set is in `../../../_superseded/2026-10-22/`.
- `Implementation/sysmonitor/` — SysMonitor service, Docker image definition, dependencies, and unit tests.
- `Implementation/mqtt/` — MQTT 5 mutual-X.509 broker configuration and least-privilege ACL.
- `Implementation/security/` — OpenSSL certificate extension profiles. Private keys and issued certificates are intentionally excluded.
- `Implementation/scripts/` — Authentication identity and ConsumerAuthorization policy provisioning.
- `Implementation/integration/` — the tested local-cloud Compose/Make deployment and the components modified to publish, store, and display SysMonitor telemetry.

## Verification

Run the standalone unit tests from `Implementation/sysmonitor`:

```sh
python3 -m unittest discover -s test -v
```

In the Arrowhead test-cloud repository, deployment is performed with:

```sh
make up-sysmonitor
```

The deployed management API is `https://127.0.0.1:8475`; it requires a trusted Arrowhead client certificate and a matching Authentication identity token. MQTT is exposed as mutual-TLS MQTT 5 on port `8883`.

## Security note

The generated CA private key, system private keys, PKCS#12 stores, SQLite runtime data, container images, and Python bytecode are not included in this package. Generate deployment identities using the supplied certificate profiles and the test-cloud provisioning workflow.
