\section{Overview}
\label{sec:overview}

This document describes the \texttt{sysMonitorHistory} service, which provides query of the stored sysMonitor observations of every monitored system.
It is produced by the SysMonitor system \cite{smo-sysd} in service version 1.0.0.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interface is specified in the HTTP/TLS/JSON IDD \cite{smo-sysMonitorHistory-http-idd}.

\subsection{Significant Prior Art}

New in this workspace (SysMonitor-History-HTTP-IDD-5.2.2).

\subsection{How This Service Is Meant to Be Used}

LocalCloudManager and the Plant\allowbreak{}Description\allowbreak{}Engine read the systems, the latest observation per type and the history of a system.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

Every operation needs a Consumer\allowbreak{}Authorization grant (\texttt{sysMonitorHistory}, scope = operation; cached 30 s). History is kept \texttt{SYSMONITOR\_\allowbreak{}RETENTION\_\allowbreak{}DAYS} (30) days.

\section{Service Interface}
\label{sec:operations}

This section describes the interfaces to the \texttt{sysMonitorHistory} service.
In particular, each subsection names an abstract operation, an input type and an output type, in that order.
The input type is named inside parentheses, while the output type is preceded by a colon.
Input and output types are only denoted when accepted or returned, respectively, by the interface in question.

All abstract data types named in this section are defined in Section \ref{sec:model}.

The following interface operations are available.

\osubsection{list-systems}{}{\mref{SystemList}}

Returns the systems with stored observations.

\osubsection{query}{\pref{Name}}{\mref{ObservationList}}

Returns observations of a system, optionally by type and period (\texttt{count} 1..1000, default 100).

\osubsection{latest}{\pref{Name}}{\mref{Latest}}

Returns the latest observation per type of a system (404 if none).
