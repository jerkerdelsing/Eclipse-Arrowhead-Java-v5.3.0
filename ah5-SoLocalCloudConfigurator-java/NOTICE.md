SoLocalCloudConfigurator: System of LocalClouds design, policy planning and deployment packages. Policy engine and inter-cloud
planning adapted from the primary Java SoSConfigurator (without ColonyOS); service skeleton (security filters, JPA, system
info) adapted from the primary Java LocalCloudConfigurator; the deployment kit (kit/cloud) is generated by tools/make-kit.py
from the v5.3.0 Java test cloud's scripts and configuration; kit/bin/sos-cloud.sh is SoSConfigurator's scripts/sos-cloud.sh;
org/relay/crl-watch.sh and its Dockerfile come from the Arrowhead relay project. Common library sources are vendored in
vendor/. SPDX-License-Identifier: EPL-2.0. No credentials copied.
