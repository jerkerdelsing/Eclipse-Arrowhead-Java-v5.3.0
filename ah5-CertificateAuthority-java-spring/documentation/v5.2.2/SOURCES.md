# Sources and maintenance

The documents retain the Eclipse Arrowhead document templates and local class/assets. Current implementation facts come from this project's `src/main/java/eu/arrowhead/port`, `pom.xml`, `Dockerfile`, `compose.yaml` and `.env.example`. The reference source was copied from JavaSupportRuntime on 25 October 2026 and separated into system-owned code. Historical content is in `legacy/`.

The original combined-tree generator was used for the initial 22 October documents. These current sources are maintained locally and can be compiled without that generator or any sibling source folder. The updated support GSoSDD is in the enclosing distribution's `roadmap/5.2/Arrowhead SoS architecture/WhiteBox_5.2.2`. Documents remain release candidates pending quality assurance.
