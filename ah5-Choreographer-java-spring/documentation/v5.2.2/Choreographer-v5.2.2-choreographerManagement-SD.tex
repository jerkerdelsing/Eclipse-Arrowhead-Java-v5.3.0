\section{Overview}
\label{sec:overview}

This document describes the \texttt{choreographer\allowbreak{}Management} service, which provides operator management of plans, sessions, session steps, the worklog and executors.
It is produced by the Choreographer system \cite{cho-sysd} in service version 1.0.0.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interface is specified in the HTTP/TLS/JSON IDD \cite{cho-choreographerManagement-http-idd}.

\subsection{Significant Prior Art}

Successor of the Arrowhead 4.6 Choreographer management endpoints.

\subsection{How This Service Is Meant to Be Used}

Operators create, check and remove plans, start and abort sessions, follow sessions, steps and the worklog, and manage executors.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

Access follows the management policy (standalone deployment: \texttt{sysop-\allowbreak{}only}).

\section{Service Interface}
\label{sec:operations}

This section describes the interfaces to the \texttt{choreographer\allowbreak{}Management} service.
In particular, each subsection names an abstract operation, an input type and an output type, in that order.
The input type is named inside parentheses, while the output type is preceded by a colon.
Input and output types are only denoted when accepted or returned, respectively, by the interface in question.

All abstract data types named in this section are defined in Section \ref{sec:model}.

\osubsection{query-plans}{}{\mref{PlanListResponse}}

Returns a page of plans.

\osubsection{get-plan}{\pref{Identifier}}{\mref{PlanResponse}}

Returns a plan.

\osubsection{create-plan}{\mref{PlanRequest}}{\mref{PlanResponse}}

Validates and stores a plan (cycles, reachability, transitive reduction).

\osubsection{remove-plan}{\pref{Identifier}}{}

Removes a plan.

\osubsection{check-plan}{\pref{Identifier}}{\mref{CheckPlanResponse}}

Checks whether providers and executors exist for every step.

\osubsection{start-sessions}{\mref{RunPlanListRequest}}{\mref{RunPlanListResponse}}

Starts sessions of plans by identifier.

\osubsection{abort-session}{\pref{Identifier}}{}

Aborts a session.

\osubsection{query-sessions}{}{\mref{SessionListResponse}}

Returns a page of sessions.

\osubsection{query-session-steps}{}{\mref{SessionStepListResponse}}

Returns a page of session steps.

\osubsection{query-worklog}{}{\mref{WorklogListResponse}}

Returns a page of worklog entries.

\osubsection{query-executors}{}{\mref{ExecutorListResponse}}

Returns a page of executors.

\osubsection{get-executor}{\pref{Identifier}}{\mref{ExecutorResponse}}

Returns an executor.

\osubsection{create-executor}{\mref{ExecutorCreateRequest}}{\mref{ExecutorResponse}}

Registers an executor on behalf of a system.

\osubsection{remove-executor}{\pref{Identifier}}{}

Removes an executor.
