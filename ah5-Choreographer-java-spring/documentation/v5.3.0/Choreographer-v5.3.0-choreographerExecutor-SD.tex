\section{Overview}
\label{sec:overview}

This document describes the \texttt{choreographer\allowbreak{}Executor} service, which provides registration of executor systems and reporting of executed plan steps.
It is produced by the Choreographer system \cite{cho-sysd} in service version 1.0.0.

The rest of this document is organized as follows.
In Section \ref{sec:operations}, we describe the abstract message operations provided by the service.
In Section \ref{sec:model}, we end the document by presenting the data types used by the mentioned operations.
The concrete interface is specified in the HTTP/TLS/JSON IDD \cite{cho-choreographerExecutor-http-idd}.

\subsection{Significant Prior Art}

Successor of the Arrowhead 4.6 Choreographer executor services (\texttt{notifyStepDone} became \texttt{notify-\allowbreak{}step-\allowbreak{}done}).

\subsection{How This Service Is Meant to Be Used}

An executor registers itself with \texttt{register} (address, port, base path and the service definition it executes steps for), reports each finished step with \texttt{notify-\allowbreak{}step-\allowbreak{}done}, and leaves with \texttt{unregister}.

\subsection{Important Delimitations and Dependencies}
\label{sec:delimitations}

The executor address must be one of its ServiceRegistry addresses; a step result is accepted only from the step's executor.

\section{Service Interface}
\label{sec:operations}

This section describes the interfaces to the \texttt{choreographer\allowbreak{}Executor} service.
In particular, each subsection names an abstract operation, an input type and an output type, in that order.
The input type is named inside parentheses, while the output type is preceded by a colon.
Input and output types are only denoted when accepted or returned, respectively, by the interface in question.

All abstract data types named in this section are defined in Section \ref{sec:model}.

The following interface operations are available.

\osubsection{register}{\mref[Executor\allowbreak{}Registration\allowbreak{}Request]{ExecutorRegistrationRequest}}{\mref{ExecutorResponse}}

Registers the requester as executor for a service definition (version window).

\osubsection{unregister}{}{}

Removes the requester's executor registration.

\osubsection{notify-step-done}{\mref{ExecutedStepResult}}{}

Reports the result of a session step executed by the requester.
