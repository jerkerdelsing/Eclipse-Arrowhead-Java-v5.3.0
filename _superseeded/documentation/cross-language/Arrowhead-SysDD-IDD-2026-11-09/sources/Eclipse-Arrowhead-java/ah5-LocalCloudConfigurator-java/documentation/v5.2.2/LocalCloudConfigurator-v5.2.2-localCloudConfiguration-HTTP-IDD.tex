\label{sec:overview}

It's implemented using protocol, encoding as stated in below table:

    Encoding & JSON & RFC 8259 \cite{rfc8259} \\ \hline
    Compression & N/A & - \\ \hline
    Semantics & N/A & - \\ \hline

\section{Service Operations}
\label{sec:operations}

Each subsection names the HTTP method and path of an operation, the abstract operation of the SD and its input and output types.

Every request needs the caller's client certificate (mutual TLS) and \texttt{Authorization:\allowbreak{} Bearer IDENTITY-\allowbreak{}TOKEN/\allowbreak{}/\allowbreak{}<token>} of the same system; the operation is allowed for Sysop, the systems of \texttt{lcc.\allowbreak{}api.\allowbreak{}whitelist} and systems with a ConsumerAuthorization grant of the operation. These checks answer 401 and 403 with the common error body (\texttt{errorMessage}, \texttt{errorCode}, \texttt{exceptionType}, \texttt{origin}); other \texttt{/api} paths are refused (403) before any handler. Request bodies are JSON of at most 64 KiB (413 \texttt{"Request exceeds 64 KiB"}); unknown fields are rejected (400). Errors of the operations are \texttt{\{"error": "<text>"\}} with 400 (invalid input), 404, 409 (stale plan, running deployment, changed design), 413 and 502 (backend failure, redacted message). Responses carry \texttt{Cache-Control: no-store}, \texttt{X-Content-Type-Options: nosniff} and \texttt{Content-Security-Policy: default-src 'none'; frame-ancestors 'none'}. Absent \texttt{null} fields are omitted.

The component catalog of the cloud.

A successful call returns \texttt{200 OK}.

Host: localcloudconfigurator:8492
Authorization: Bearer IDENTITY-TOKEN//<token of LocalCloudManager>
\end{lstlisting}

\osubsection{status}{GET}{/\allowbreak\{\}api/\allowbreak\{\}status}{}{\mref{Status}}

Running Compose services and the state (\texttt{running}, \texttt{partial}, \texttt{stopped}) of each component (cached 2 s).

A successful call returns \texttt{200 OK}. Errors: 502 when the backend cannot report the runtime.

\begin{lstlisting}[label={lst:status},caption={An \oref{status} invocation.}]
GET /api/status HTTP/1.1
Host: localcloudconfigurator:8492
Authorization: Bearer IDENTITY-TOKEN//<token of LocalCloudManager>
\end{lstlisting}

\begin{lstlisting}[label={lst:status-resp},caption={An \oref{status} response.}]
{
  "cloud": "TestCloud",
  "running": ["serviceregistry-db", "serviceregistry", ...],
  "systems": [{"id": "serviceregistry", "state": "running"},
              {"id": "timemanager", "state": "stopped"}, ...]
}
\end{lstlisting}

\osubsection{plan}{POST}{/\allowbreak\{\}api/\allowbreak\{\}plan}{\mref{PlanRequest}}{\mref{PlanResponse}}

Builds a plan against the current runtime; returns it with its hash.

A successful call returns \texttt{200 OK}. Errors: 400 for an unknown component, a forbidden removal (protected, selected, still required) or a dependency cycle.

\begin{lstlisting}[label={lst:plan},caption={An \oref{plan} invocation.}]

Host: localcloudconfigurator:8492
Authorization: Bearer IDENTITY-TOKEN//<token of LocalCloudManager>
Content-Type: application/json

{
  "systems": ["timemanager"],
  "remove": [],
  "reapply": false,
  "smoke": true
}
\end{lstlisting}

\begin{lstlisting}[label={lst:plan-resp},caption={An \oref{plan} response.}]
{
  "plan": {
    "cloud": "TestCloud",
    "catalogHash": "9f2c...",

\osubsection{submit-deployment}{POST}{/\allowbreak\{\}api/\allowbreak\{\}deployments}{\mref{ApplyRequest}}{\mref{DeploymentAccepted}}

Applies a reviewed plan if its hash still matches a fresh plan and no other deployment is running.

A successful call returns \texttt{202 Accepted (200 OK when the plan has no steps)}. Errors: 409 \texttt{"Plan or cloud state changed. Review a fresh plan before applying."} or \texttt{"A deployment is still running. Wait for it before applying another plan."}; 400 as for \oref{plan}; 502 when the backend fails.

\begin{lstlisting}[label={lst:submit-deployment},caption={An \oref{submit-deployment} invocation.}]
POST /api/deployments HTTP/1.1
Host: localcloudconfigurator:8492
Authorization: Bearer IDENTITY-TOKEN//<token of LocalCloudManager>
Content-Type: application/json

{
  "systems": ["timemanager"],
  "remove": [],
  "reapply": false,
  "smoke": true,
  "expectedPlanHash": "41d8..."
}
\end{lstlisting}

\begin{lstlisting}[label={lst:submit-deployment-resp},caption={An \oref{submit-deployment} response.}]
{
  "id": "local-0f8e2a1c-6d4b-4a3e-9c1d-2b7f5e8a9c01",
  "plan": { ... },
  "state": "submitted"
}
\end{lstlisting}
