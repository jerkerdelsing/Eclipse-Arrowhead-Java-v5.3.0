# Eclipse Arrowhead documentation edition 5.3.0

Created 9 November 2026. LaTeX is the editable source of record; every listed top-level LaTeX document has a freshly compiled PDF beside it.

295 PDFs in 26 per-system edition folders: all 287 existing versioned LaTeX documents were carried forward, including two native catalogues, and eight missing SoSConfigurator descriptions were added from its primary source. This covers the five Java core systems and nineteen Java support systems, plus the separately versioned Go/Rust LocalCloudManager sets. Unversioned native catalogues elsewhere were outside the requested v5.2.2-to-v5.3.0 conversion. Historical trees and earlier cross-language compilations were not used as the baseline.

The new per-system folders are documentation/v5.3.0. The Go LocalCloudManager baseline was nested under documentation/LocalCloudManager/v5.2.2; the new edition is directly under documentation/v5.3.0. Rust LocalCloudManager documentation retains its existing link into the primary shared catalogue.

All original v5.2.2 folders and files are retained unchanged; SHA-256 verification covered 845 existing files.

Document metadata, current edition references, bibliography edition numbers and revision histories were updated. Runtime/dependency versions, service versions and wire payload identifiers retain source-defined values. In particular, the source still uses the SysMonitor-AMQP-IDD-5.2.2 payload identifier; this was not falsified by changing a documentation edition. No implementation or deployment was changed.

All Java SysDDs and IDDs include Go and Rust implementation sections, with absent ports and native compatibility boundaries stated. Source-specific build, state, security and listening-port details distinguish the implementations.

## Validation

- All 295 standalone LaTeX documents compiled with latexmk/pdfLaTeX; bibliography passes were run where used.
- Every PDF reopened successfully and displays document version 5.3.0. PDFs are newer than their LaTeX source.
- No unresolved references, citations, multiply defined labels or missing-character errors remain.
- Missing inherited Array primitive anchors and the large inherited path/property overflows were corrected in the new copies only. Small inherited layout warnings (about 1.9-3.3 pt) remain; selected covers and detailed pages were rendered and inspected.
- The Rust manager edition includes a local copy of its class/figures, so it builds independently of the old catalogue location.
- The SoSConfigurator sysMonitor descriptions reuse the byte-identical common publisher contract, with its own references and absence of Go/Rust ports documented.
- All original v5.2.2 file hashes were checked before installation and are checked again after installation.
- Build each new edition with its own build-docs.sh. Do not use older generators that still target v5.2.2.

Full document/hash validation and preservation manifests are in [v5.3.0-validation](../../documentation/v5.3.0-validation/).
